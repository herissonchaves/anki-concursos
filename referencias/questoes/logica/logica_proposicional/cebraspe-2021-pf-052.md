# Cebraspe 2021 — PF — item 52

## Enunciado

> P1: Se a fiscalização foi deficiente, as falhas construtivas não foram corrigidas. P2: Se as falhas construtivas foram corrigidas, os mutuários não tiveram prejuízos. P3: A fiscalização foi deficiente. C: Os mutuários tiveram prejuízos.
>
> Considerando um argumento formado pelas proposições precedentes, em que C é a conclusão, e P1 a P3 são as premissas, julgue os itens a seguir.

A proposição P2 é equivalente a “Se as falhas construtivas não foram corrigidas, os mutuários tiveram prejuízos”.
