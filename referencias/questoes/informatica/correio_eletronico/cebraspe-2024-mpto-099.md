# Cebraspe 2024 — MPTO — item 99

## Enunciado

> Julgue os itens subsequentes, a respeito de redes de computadores.

Um serviço de endereço de correio eletrônico pela Internet utiliza dois protocolos: o SMTP (simple mail transfer protocol), protocolo padrão para recebimento das mensagens; e o POP (post office protocol), para o envio das mensagens.

## Gabarito

**Errado** — definitivo ([gabarito oficial](https://cdn.cebraspe.org.br/concursos/MP_TO_24_SERVIDOR/arquivos/GAB_DEFINITIVO_952_MP_TO_016_01.PDF))

## Análise

Inverte os papéis: SMTP envia/transfere mensagens; POP (assim como IMAP) é usado pelo cliente para receber.
