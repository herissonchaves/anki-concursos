# Cebraspe 2021 — PF — item 45

## Enunciado

> | 3,5 | 5,3 | 3,8 | 3,1 | 3,5 |
> | --- | --- | --- | --- | --- |
>
> Considerando que o conjunto de dados apresentado represente uma realização de uma amostra aleatória simples de tamanho n = 5 retirada de uma população X, cuja função de probabilidade acumulada é escrita como P(X ≤ x) = 1 − (β/x)², se x ≥ β; e P(X ≤ x) = 0, se x < β, em que β é o parâmetro desconhecido, julgue os itens que se seguem.

A média amostral é uma estatística suficiente para a estimação do parâmetro β.
