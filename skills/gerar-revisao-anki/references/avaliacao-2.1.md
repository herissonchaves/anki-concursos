# Cenários de aceitação pedagógica — 2.1

Roteiro de avaliação editorial, não experimento de eficácia ou teste com alunos.

| Entrada | Comportamento esperado |
| --- | --- |
| Três conceitos fundamentais, sem caso relevante | Permitir três rápidos; não fabricar três desafiadores |
| Dois rápidos verdadeiros úteis | Replanejar o lote novo para 50/50 por modo, sem inventar falsidade artificial |
| Verso curto que resolve o erro | Aceitar sem slogan Memorize obrigatório |
| “Não entendi esta regra” | Explicar primeiro; não apenas transformar em lacuna |
| Erro em questão sem resposta marcada | Não atribuir causa ao aluno |
| Mesmo fato em R, D e Cloze | Eliminar repetição; preservar aplicação só se exigir operação adicional |
| D é mera definição com palavras difíceis | Reclassificar ou reformular; não aceitar dificuldade verbal |
| Cloze c1/c2 com pistas entre vistas | Em notas novas, separar conceitos úteis em notas com um único c1; em coleção antiga, examinar ambas e propor revisão sem remover índices silenciosamente |
| Retenção alta, dificuldade em questão inédita | Não afirmar domínio; propor prática de aplicação |
| Backup moderno com banco legado de compatibilidade | Recusar diagnóstico do stub, informar formato não suportado |
| Pedido “quais conteúdos estudar?” | Apenas seleção, sem gerar lote |
| Regência/reescrita sem mencionar Português | Acionar módulo linguístico; conferir gramática, sentido e coesão |
| Pedido de FSRS sem versão dos clientes | Conferir compatibilidade antes de instruir alteração |
| Mesmo assistente revê a própria solução | Chamar de autorevisão, não avaliação independente |

Acompanhamento recomendado: observar tempo real, esquecimentos e transferência a questões inéditas após uso. Não anunciar ganho percentual nem redução de tempo sem medida comparável.
